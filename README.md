# EcoDash-African-Logistics
 An Interactive 2D Simulation that was built using HTML, CSS, and JavaScript. The project displays how mathematics was used to calculate the vehicle speed, how the turns based on the vehicle's direction, how it manages in different conditions whether that be environment or the weather, and collision calculation within the African Environment.

 #Features
 Vehicle speed
 Acceleration: Moves quite quickly when you change it based on conditions of the    environment.
 Battery Consumption: The faster the dron the faster the batter drains.
 Wind Resistance: Wind resistance meaning slows down  down, easier to see obstacles
 Collision with objects

# How to Use
Decide on a character before you play the game.
The colour of the character is the same colour of the drone 
There's an expert and beginner level. The beginner level moves at an even pace while the expert increases in speed.
monitor the heat of the drone by regulating the drop rate of the battery
Last but not least, Have fun!
